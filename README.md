## 🛠 Installation

```bash
# Clone the repository
git clone https://github.com/Mepoify/proxy.git
cd (path)

# Install dependencies
npm install

# Start the proxy server
node server.js
```

> **Note:** Ensure you have [Node.js](https://nodejs.org/) installed before running the server.
